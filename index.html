BloomFilter

Bloom filters are space-efficient probablistic data structures used to test whether an element is a member of a set. Discovered by Burton Howard Bloom in 1970

The explanation of bloomfilter is pretty standard and the parameters which it depends upon will be explained here.
If you want to read more about bloomfilters i have listed some good resources later in the section

Bloomfilter depends on following factors:

  • an array of m bits

  • k: different hash functions count

  • p: false positive probablity exclusively (0, 1)

  • n: expected number of elements in bloomfilter
